# Logos

`smartsplit-mark.svg` is the project's own app mark from the repo's `public/favicon.svg`: a white "S" stroke on a red rounded square. Its red is the repo's original `#e60000`, which is close to `brand-strong`. Use it as the app icon and favicon, at 24px or larger.

The DBS logo is deliberately not included. This is a student concept that isn't affiliated with DBS Bank, so don't add DBS marks to screens.
