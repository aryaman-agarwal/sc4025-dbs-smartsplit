# HeroHeader

The red gradient header for the SmartSplit home, with the white sheet (`.ss-sheet`) overlapping it.

Only the home screen uses it. Gradient `brand-deep` → `brand-strong`, all text `on-brand`. The greeting is personal and the sub-line gives your position in one sentence. Below it, wrap content in `<div class="ss-sheet">`, which has `radius-lg` top corners and the pink `sheet` tint.

_hand-written from `src/components/ui.tsx` (aryaman-agarwal/sc4025-dbs-smartsplit@c703620) and restyled after the DBS app screenshots._
