# Field

A labelled text input with an optional hint.

Focus shows a `brand-strong` border and a `brand-soft` ring. The consumer supplies `label`, an optional `hint`, and `inputProps` passed to the `<input>`. For amounts, set `inputMode:"decimal"` and convert to cents before storing.
