# QuickAction

A shortcut: a pink disc with a red line icon and a label underneath, like the app's Security Hub and PayNow row.

The default `disc` goes in the horizontal row on the home sheet (up to five). The `tile` variant (white rounded square, grey icon) goes in three-column grids on More-style screens. `dot` marks something unread and `isNew` adds a NEW pill. Labels are at most two short lines. The consumer supplies `icon` (an Icon name), `label` and `onClick`.
