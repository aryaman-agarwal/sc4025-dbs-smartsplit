# Icon

Line icons in a 24px grid, 1.8 stroke, round caps. They follow the app's thin red line style and the repo's lucide-react icons.

Each one inherits `currentColor`: `brand` on quick-action discs, `muted` on tiles and chevrons, `on-brand` in the hero. The set covers SmartSplit's needs, and in the React app the matching lucide-react icons stand in. Icons are decorative (`aria-hidden`), so label the button that holds them.

_hand-written from `src/components/ui.tsx` (aryaman-agarwal/sc4025-dbs-smartsplit@c703620) and restyled after the DBS app screenshots._
