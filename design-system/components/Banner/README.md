# Banner

An inline message in one of four tones: info, warn, error and success.

Use warn for scam checks (first-time payee) and error for anything that blocks Save or Pay. Each tone has its own icon, so the meaning never rests on colour alone. Keep it to one or two sentences that say what happened and what to do.
