# Avatar

A circle with a member's initials, shown alone or overlapped in a stack for a group.

The consumer supplies `name` and `color` (one of the `avatar-*` tokens) and a `size` (26–40). Stacks show up to four, overlapping by `space-2`, with a white ring. Never use a real photo of a payee in a payment step: the app shows masked names there.

_hand-written from `src/components/ui.tsx` (aryaman-agarwal/sc4025-dbs-smartsplit@c703620) and restyled after the DBS app screenshots._
