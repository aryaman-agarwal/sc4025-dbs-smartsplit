# Badge

Small markers: a grey count chip, a red NEW pill and a red unread dot.

Use the count chip next to card titles ("Deposits 2"), NEW on a feature tile for its first weeks, and the dot on icons with unread items. Use one marker per item. The dot is colour only, so give it a `label` for screen readers.
