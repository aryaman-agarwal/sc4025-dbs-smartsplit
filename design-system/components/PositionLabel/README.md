# PositionLabel

Shows where you stand in a group: "You owe SGD X", "You are owed SGD X" or "Settled".

The words carry the meaning and the colour (`owe`, `owed`, `muted`) only supports it, so it stays readable for colour-blind users. Pass `balance` in cents: negative means you owe.
